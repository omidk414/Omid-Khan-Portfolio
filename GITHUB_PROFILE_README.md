## About me

I'm a **data engineer and software developer** working across data pipelines, cloud infrastructure, analytics, and machine learning. I enjoy building end-to-end systems—from collecting and transforming raw data to delivering useful applications and dashboards.

- 🎓 **M.S. in Data Science**, University of California, Berkeley; **B.S. in Computer Science**, California State University, East Bay.
- 🔧 Experience with **Python, SQL, Azure, Google Cloud, PostgreSQL, Power BI**, and applied ML.
- 🧠 Interested in **data engineering, AI systems, automation, and product development**.
- 💿 Building **OnlyPhysys**, a platform for cataloging physical media, tracking collection value, and eventually connecting collectors through trades.
